Measuring intelligence reliably takes more than writing a list of hard
questions. Clinically-used tests go through years of development before
they're considered valid — here's the actual process, in plain language.

## 1. Build subtests for distinct cognitive domains

A real test, like the Wechsler Adult Intelligence Scale, isn't one block
of questions — it's a set of subtests, each targeting a different ability
(vocabulary, working memory, processing speed, visual puzzle-solving).
Keeping them separate lets the test report a profile, not just one number
— someone can be well above average on verbal reasoning and only average
on processing speed, and a single composite score would hide that.

## 2. Pilot the questions on a large, representative sample

Before a question counts for anything, it's tested on thousands of
people across different ages, backgrounds, and regions. Questions that
turn out to be ambiguous, culturally loaded, or that don't actually
correlate with the rest of the subtest get thrown out. This piloting
phase is where most of the actual cost and time of building a real test
goes.

## 3. Norm the score against that sample

Once the final item set is fixed, the test is given to a large norming
sample, and that sample's results become the reference distribution — the
famous "mean 100, standard deviation 15" bell curve is a description of
that reference group's scores, not a property of intelligence itself. Your
raw number of correct answers only becomes a meaningful "IQ" once it's
placed on that distribution.

## 4. Check reliability and validity

A test also has to prove it gives consistent results if you take it twice
(reliability) and that it actually measures reasoning ability rather than,
say, reading speed or test-taking familiarity (validity). Published tests
report these statistics; an online quiz that skips this step is skipping
the part that makes a score trustworthy in the first place.
